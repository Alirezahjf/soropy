# مثال‌های کاربردی WebSocket در SoroPy 1.3.4

این سند نقطهٔ شروع سریع برای مثال‌های آمادهٔ WebSocket / MTProto است.

| فایل | توضیح |
|---|---|
| [`soropy/examples/websocket/group_moderator.py`](../soropy/examples/websocket/group_moderator.py) | مدیر گروه ضدلینک، ضدواژه، ضد flood، ضد تکرار و سه اخطار |
| [`soropy/examples/websocket/ai_assistant.py`](../soropy/examples/websocket/ai_assistant.py) | دستیار AI با OpenAI، compatible APIs، Gemini، Claude و Ollama |
| [`soropy/examples/websocket/capability_cookbook.py`](../soropy/examples/websocket/capability_cookbook.py) | cookbook همهٔ قابلیت‌های WebSocket بدون اجرای خودکار عملیات خطرناک |
| [`soropy/examples/websocket/support_desk_bot.py`](../soropy/examples/websocket/support_desk_bot.py) | میز پشتیبانی ticket-based با state اتمیک و فرمان‌های اپراتور |
| [`soropy/examples/websocket/campaign_broadcaster.py`](../soropy/examples/websocket/campaign_broadcaster.py) | کمپین پیام‌رسانی امن با dry-run پیش‌فرض و confirm اجباری |
| [`soropy/examples/websocket/event_audit_logger.py`](../soropy/examples/websocket/event_audit_logger.py) | Audit logger JSONL با sanitize فیلدهای حساس |
| [`soropy/examples/websocket/README.md`](../soropy/examples/websocket/README.md) | راهنمای کامل نصب، env، امنیت، AI، moderation، پشتیبانی و کمپین |

> برای تست endpoint واقعی به حساب آزمایشی سروش‌پلاس و گروه آزمایشی نیاز دارید.
